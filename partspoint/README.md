# PartsPoint HTML upload files

[Download the PartsPoint website ZIP](https://github.com/Shuyi0715/MBG/raw/refs/heads/main/partspoint/partspoint-website-upload.zip)

The `website/` directory contains the same unpacked files. This is the current single-page PartsPoint design, with all page sections included in `website/index.html`. CSS, JavaScript, fonts, and the transparent logo are supplied locally in `assets/` and `images/`. No Node.js, npm, or WordPress installation is required on IONOS.

## Upload to IONOS

1. Download and extract `partspoint-website-upload.zip` on your computer.
2. Create a separate empty preview folder in IONOS Webspace Explorer.
3. Upload **all extracted contents**, including `index.html`, `assets/`, `images/`, `robots.txt`, and `.htaccess`, directly into that folder. Uploading just the ZIP or just `index.html` will not install the complete design.
4. Open the folder through your configured preview subdomain or website subfolder URL. Relative asset paths support either arrangement.
